# Incident Report 004 - File Integrity Monitoring

## Alert Information

- Platform: Wazuh SIEM
- Agent: Ebenezer (Windows 11)
- Monitoring Technology: File Integrity Monitoring (FIM)

## Test Environment

A dedicated test directory was created:

C:\SOC-Lab-Test

A test file named `soc-test.txt` was created, modified, and deleted to validate Wazuh FIM detection.

## Detection 1 - File Integrity Change

- Rule ID: 550
- Description: Integrity checksum changed
- Severity Level: 7

Wazuh detected a change to the monitored file's integrity checksum.

## Detection 2 - File Deletion

- Rule ID: 553
- Description: File deleted
- Severity Level: 7

Wazuh detected the deletion of the monitored test file.

## Investigation

The activity was intentionally generated as part of a controlled SOC laboratory exercise.

The monitored file was created, modified, and subsequently deleted.

## Analysis

The alerts were successfully generated by Wazuh FIM.

No malicious activity was involved.

The exercise confirmed that the Windows endpoint is successfully monitored for file integrity changes.

## Classification

Benign Lab Activity

## SOC Analyst Response

No incident response was required because the activity was authorised testing.

In a production environment, unexpected modification or deletion of a monitored file would require further investigation.

## Status

Closed
